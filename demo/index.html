What this demo is, and is not

This is the retrieval half of the RAG pipeline: the document is split into chunks, each chunk is embedded with all-MiniLM-L6-v2, and your question is matched by cosine similarity. It works best in English.

The full application adds the generation half: a FastAPI backend, OpenAI embeddings, a Pinecone vector index and an LLM that answers using only the retrieved chunks. That part needs paid API keys, so it is not hosted here. Source on GitHub.
